Import email or documents

Choose a ZIP already saved on this computer. Clippi-Health reads it locally during the rebuild; it never signs in to an email account or contacts an email service.

GmailSearch, select the matching conversations, and apply a temporary label. In Google Takeout, deselect everything, select Mail, choose only that label under “All Mail data included,” and create a one-time ZIP export.
Outlook 365In Outlook on the web or new Outlook, search, open each result, and use More actions (…) → Download. Put the downloaded .eml files in one folder, then compress that folder to ZIP.
DocumentsPut the PDFs, DOCX, HTML, text, XML, or image files you want to add in a folder, then compress that folder to ZIP.

Gmail Takeout MBOX and standard EML are supported. Outlook PST, OLM, and MSG files are not read yet.

Connect or import from a provider

Use the provider's own sign-in page. Where verified OAuth is available, the local helper downloads FHIR directly to this computer and forgets the token when the import ends. Other cards give provider-specific download and Apple Health instructions.

Add health data

An Apple Health export ZIP (iPhone → Health → profile → Export All Health Data), a portal “Download my record” folder, or loose PDFs. Files are copied into the local data folder — the build never changes them.

Rebuild the record

Reads everything in raw/ and writes data/health.db, the reference documents and dashboard.html. The Apple device-data pass takes about 30 seconds.
